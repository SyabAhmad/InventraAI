## How to read these docs

Each phase document is written for humans, not machines. You will find:

- What the phase does, in one paragraph.
- A simple list of what was built.
- Step-by-step instructions you can copy and paste.
- A short glossary of technical words.

If something is unclear, open an issue or ask the team.
